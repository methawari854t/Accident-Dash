รูปแบบคอลัมน์ที่รองรับใน Google Sheet:

• case_id / id, disease / โรค, onset_date / วันที่เริ่มป่วย

• province / จังหวัด, district / อำเภอ, status / สถานะ

• age / อายุ, sex / gender / เพศ, latitude / lat, longitude / lng

คู่มือการนำไฟล์ HTML นี้ไปโฮสต์บน GitHub Pages

คุณสามารถสร้างเว็บไซต์แดชบอร์ดระบาดวิทยาให้ทีมงานหรือสาธารณชนเข้าถึงได้ฟรีตลอด 24 ชั่วโมง โดยทำตาม 4 ขั้นตอนง่ายๆ ดังนี้:

ขั้นตอนที่ 1: บันทึกไฟล์ HTML นี้

บันทึกซอร์สโค้ดของหน้านี้เป็นไฟล์ชื่อ index.html บนเครื่องคอมพิวเตอร์ของคุณ

ขั้นตอนที่ 2: สร้าง Repository บน GitHub
  1. เข้าสู่เว็บ GitHub.com แล้วล็อกอิน
  2. กดปุ่ม New Repository (ตั้งชื่อ เช่น epi-dashboard)
  3. ตั้งค่าสิทธิ์เป็น Public จากนั้นกด Create Repository
ขั้นตอนที่ 3: อัปโหลดไฟล์ index.html

ในหน้า Repository ที่สร้างขึ้น กดปุ่ม uploading an existing file แล้วลากไฟล์ index.html ลงไป แล้วกด Commit Changes

ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages
  1. ไปที่เมนู Settings > Pages ของ Repository นั้น
  2. ในส่วน Build and deployment เลือก Source เป็น Deploy from a branch
  3. เลือก Branch เป็น main (หรือ master) แล้วกด Save
  4. รอประมาณ 1-2 นาที คุณจะได้ URL ประจำแดชบอร์ด เช่น:
    https://YOUR-USERNAME.github.io/epi-dashboard/
